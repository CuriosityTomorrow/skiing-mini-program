# Grid View 列表页功能说明

## 概述

全新的 Nomads.com 风格滑雪场列表页，展示强大的筛选、排序和数据可视化功能。

---

## 主要功能

### 1. 搜索功能
- 关键词搜索滑雪场名称、城市、地区
- 实时搜索结果更新
- 自动调用高德API或本地数据

### 2. 筛选系统（20+ 维度）

#### 价格筛选
- **预算型** (<300元/天)
- **中端** (300-600元/天)
- **高端** (>600元/天)

#### 难度级别
- 初级
- 中级
- 高级
- 专家级

#### 必备设施（8种）
- 租雪具
- 教练
- 夜场
- 住宿
- 餐厅
- 儿童区
- 单板公园
- 停车场

#### 适合人群
- 新手
- 亲子
- 高手
- 周末游
- 度假

#### 类型
- 室外
- 室内

**特性**：
- 多选支持（难度、设施、人群可多选）
- 单选支持（价格、类型）
- 实时显示已激活筛选数量
- 一键重置筛选

### 3. 排序系统（8种排序方式）

1. **按人气排序** - 默认排序
2. **按综合评分** - Overall Score
3. **按新手友好度** - Beginner Score
4. **按高手推荐度** - Expert Score
5. **按亲子友好度** - Family Score
6. **按性价比** - Value Score
7. **价格从低到高**
8. **按用户评分**

### 4. 卡片式展示（Grid View）

每个滑雪场卡片包含：

#### 顶部标签
- **类型标签**：室内/室外
- **优质标签**：综合评分 ≥ 8.5
- **性价比标签**：性价比 ≥ 8.0

#### 基本信息
- 滑雪场名称
- 城市和省份

#### 评分展示（Nomads风格）
- **综合评分**：大号显示，渐变色
- **4个子评分**：
  - 👶 新手友好度
  - 🎿 高手推荐度
  - 👨‍👩‍👧 亲子友好度
  - 💰 性价比

#### 关键数据
- 雪道数量
- 平均价格
- 用户评分（星级）

#### 设施图标
以 emoji 图标形式展示可用设施：
- 🎿 租雪具
- 🌙 夜场
- 🏨 住宿
- 🍴 餐厅
- 👶 儿童区
- 🏂 单板公园

## 技术实现

### 数据流
```
用户操作
  ↓
更新 filters 和 sortBy
  ↓
调用 ResortSearchAppService.getResorts()
  ↓
应用筛选（ResortFilterService）
  ↓
计算评分（ResortScoringService）
  ↓
排序结果
  ↓
渲染 UI
```

### 关键代码

#### 加载数据
```javascript
async loadResorts() {
  const result = await this.resortService.getResorts({
    keyword: this.keyword,
    filters: this.filters,
    sortBy: this.currentSort
  })

  this.list = result.data
}
```

#### 筛选切换
```javascript
toggleDifficulty(value) {
  const index = this.filters.difficulty.indexOf(value)
  if (index > -1) {
    this.filters.difficulty.splice(index, 1)
  } else {
    this.filters.difficulty.push(value)
  }
}
```

#### 排序切换
```javascript
onSortChange(e) {
  this.sortIndex = e.detail.value
  this.currentSort = this.sortOptions[this.sortIndex].value
  this.loadResorts()
}
```

### 颜色方案

- **卡片**：白色 (#fff)
- **文字**：层次分明（#333 / #666 / #999）

- 页面边距：20rpx
- 卡片间距：24rpx
- 组件内边距：16-32rpx
- 元素间距：8-16rpx

- 正文：26-28rpx
- 辅助：22-24rpx
