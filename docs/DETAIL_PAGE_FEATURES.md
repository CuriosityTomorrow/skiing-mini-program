## 数据展示规则

### 评分展示
- 分数保留1位小数
- 进度条长度 = 分数 × 10%
- 不同维度不同颜色
- 0分也显示（不隐藏）

### 雪道展示
- 总数为 total 或 totalCount
- 百分比计算：count / total × 100%
- 最小宽度5%确保可见
- 0条雪道也显示

### 价格展示
- 优先 avgCost，其次 daily
- ¥ 符号 + 数字
- 无数据显示 "-"
- 平均消费显示在底部

### 设施展示
- Boolean 值判断
- true：彩色+不透明
- false/undefined：灰色+半透明
- 全部设施都显示（不隐藏）

### 状态展示
- open：绿色
- closed：红色
- coming_soon：橙色
- 未知：默认灰色

## 技术实现

### 数据加载
```javascript
async loadResort() {
  const result = await this.resortService.getResorts({
    keyword: '',
    type: 'all'
  })

  // 查找对应ID的滑雪场
  this.resort = result.data.find(r => r.id === this.resortId)
}
```

### 雪道百分比计算
```javascript
getTrailPercentage(type) {
  const total = this.resort.trails?.total || 1
  const count = this.resort.trails?.[type] || 0
  const percent = (count / total) * 100
  return `${Math.max(percent, 5)}%`  // 最小5%
}
```

### 条件渲染
```vue
<view v-if="resort.scores && resort.scores.overall >= 8.5" class="tag premium">
  ⭐ 优质
</view>
```

## 样式系统

### 颜色方案
- **主色**：紫色渐变 (#667eea → #764ba2)
- **背景**：浅灰 (#f5f5f5)
- **卡片**：白色 (#fff)
- **分数背景**：蓝灰渐变

### 字体系统
- 标题：48rpx（超大）/ 32-36rpx（大）
- 正文：26-28rpx
- 辅助：22-24rpx
- 分数：64rpx（主）/ 48rpx（副）

### 间距系统
- 区块间距：20rpx
- 区块内边距：30rpx
- 卡片间距：16-20rpx
- 元素间距：8-16rpx
