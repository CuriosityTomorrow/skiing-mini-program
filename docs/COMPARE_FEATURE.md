# 滑雪场对比功能说明文档

## 概述

对比功能允许用户并排对比2-4个滑雪场的详细数据，帮助用户做出明智的选择决策。

---

## 使用流程

### 1. 进入对比模式

在滑雪场列表页，点击顶部的 **"⚖️ 对比"** 按钮进入对比模式。

**变化：**
- 按钮变为 **"✓ 对比中"**（高亮状态）
- 每个滑雪场卡片右上角出现圆形复选框
- 点击卡片将选择/取消选择，而不是跳转详情

### 2. 选择滑雪场

在对比模式下：
- 点击卡片选择滑雪场
- 已选择的卡片右上角复选框显示 ✓
- 最少选择 **2个**，最多选择 **4个**
- 超过4个时会提示"最多只能选择4个"

### 3. 开始对比

选择完成后：
- 页面底部出现对比操作栏
- 显示 "已选 X 个滑雪场（最多选4个）"
- 点击 **"开始对比"** 按钮跳转到对比页面
- 少于2个时按钮禁用

### 4. 查看对比结果

对比页面展示详细对比表格，包含：
- 所有6个评分维度
- 基本信息
- 价格对比
- 雪道对比
- 设施对比
- 季节信息

### 5. 退出对比

两种方式：
- 点击底部 **"返回"** 按钮
- 点击 **"清空对比"** 按钮（会清空选择）

## 对比维度

### 1. 评分对比（6个维度）

**可视化展示：**
- 数字评分（0-10分）
- 彩色进度条（不同维度不同颜色）
- 一眼识别优劣

**包含：**
- 综合评分（紫色）
- 新手友好度（青绿色）
- 中级友好度（粉色）
- 高手推荐度（橙红色）
- 亲子友好度（蓝紫色）
- 性价比（黄色）

### 2. 基本信息

- 类型（室内/室外）
- 位置（省市区）
- 用户评分（星级和评价人数）

### 3. 价格对比

- 日票价格（颜色标注：绿色便宜、橙色适中、红色昂贵）
- 夜场价格
- 周末价格
- 季卡价格

### 4. 雪道对比

- 总雪道数（高亮显示）
- 初级雪道数
- 中级雪道数
- 高级雪道数
- 专家级雪道数
- 最长雪道（米）
- 垂直落差（米）

### 5. 设施对比

11种设施一目了然：
- ✓ 绿色：有此设施
- ✗ 灰色：无此设施

**包含：**
- 租雪具
- 停车场
- 餐厅
- 住宿
- 储物柜
- 夜场
- 教练
- 魔毯
- 缆车
- 单板公园
- 儿童区

### 6. 季节信息

- 开放月份
- 雪质类型（天然雪/人工雪/混合）
- 当前状态（开放中/已关闭/即将开放）

## 设计特点

### 1. 横向滚动表格

**布局：**
- 左侧固定标签列（200rpx）
- 每个滑雪场占220rpx
- 支持横向滚动查看所有对比项

**优点：**
- 适合移动端
- 清晰对比
- 数据密度高

### 2. 彩色视觉化

**评分进度条：**
- 不同维度不同颜色
- 长度直观表示分数高低
- 易于快速对比

**价格颜色：**
- 绿色：<300元（便宜）
- 橙色：300-500元（适中）
- 红色：>500元（昂贵）

**状态标签：**
- 开放中：绿色
- 已关闭：红色
- 即将开放：橙色

### 3. 分组展示

**6大分组：**
1. 📊 评分对比
2. 📍 基本信息
3. 💰 价格对比
4. ⛷️ 雪道对比
5. 🏗️ 设施对比
6. 📅 季节信息

每组用灰色分段标题分隔，清晰易读。

### 4. 响应式设计

- 表头固定（sticky）
- 横向滚动流畅
- 手势友好
- 字体大小适中

## 使用场景

### 场景 1：新手选择

**需求：**
- 找一个新手友好的滑雪场
- 价格适中
- 有教练和租雪具

**操作：**
1. 搜索或筛选出几个候选滑雪场
2. 进入对比模式，选择3-4个
3. 在对比页查看：
   - 新手友好度分数（谁最高？）
   - 价格（谁最便宜？）
   - 设施（谁有教练和租雪具？）
4. 做出决策

### 场景 2：家庭出游

**需求：**
- 适合带孩子
- 有儿童区和餐厅
- 安全便利

**操作：**
1. 筛选"适合人群 → 亲子"
2. 选择2-3个对比
3. 查看：
   - 亲子友好度分数
   - 是否有儿童区 ✓
   - 是否有餐厅和停车场
   - 初级雪道比例

### 场景 3：高手挑战

**需求：**
- 高级道多
- 垂直落差大
- 有单板公园

**操作：**
1. 筛选"难度 → 高级+专家级"
2. 对比3个顶级滑雪场
3. 查看：
   - 高手推荐度分数
   - 高级+专家级雪道数
   - 垂直落差
   - 是否有单板公园 ✓

### 场景 4：性价比对比

**需求：**
- 找最划算的
- 雪道多但价格低

**操作：**
1. 选择几个不同价位的滑雪场对比
2. 查看：
   - 性价比分数
   - 价格（日票）
   - 雪道总数
   - 设施数量
3. 计算"每元能玩多少雪道"

## 技术实现

### 数据流

```
列表页
  ↓ 用户选择2-4个滑雪场
compareList = [resort1, resort2, resort3]
  ↓ 跳转并传递ID
/pages/resort/compare/index?ids=id1,id2,id3
  ↓ 对比页加载数据
ResortSearchAppService.getResorts()
  ↓ 筛选出对应ID的滑雪场
resorts = [resort1, resort2, resort3]
  ↓ 渲染对比表格
展示详细对比数据
```

### 关键代码

#### 列表页：选择逻辑
```javascript
toggleCompareItem(item) {
  const index = this.compareList.findIndex(r => r.id === item.id)
  if (index > -1) {
    this.compareList.splice(index, 1)  // 移除
  } else {
    if (this.compareList.length >= 4) {
      uni.showToast({ title: '最多只能选择4个', icon: 'none' })
      return
    }
    this.compareList.push(item)  // 添加
  }
}
```

#### 列表页：跳转对比
```javascript
startCompare() {
  if (this.compareList.length < 2) {
    uni.showToast({ title: '至少选择2个滑雪场', icon: 'none' })
    return
  }

  const ids = this.compareList.map(r => r.id).join(',')
  uni.navigateTo({
    url: `/pages/resort/compare/index?ids=${ids}`
  })
}
```

#### 对比页：加载数据
```javascript
async loadResorts() {
  const result = await this.resortService.getResorts({
    keyword: '',
    type: 'all'
  })

  // 筛选出要对比的滑雪场
  this.resorts = result.data.filter(r => this.resortIds.includes(r.id))
}
```

## 性能优化

### 1. 按需加载
- 只加载选中的滑雪场数据
- 不加载全部列表

### 2. 缓存复用
- 使用列表页已加载的数据
- 避免重复请求

### 3. 横向滚动优化
- 使用 `scroll-view` 组件
- 硬件加速

### 4. 样式优化
- CSS Grid 布局
- 最小化重绘
