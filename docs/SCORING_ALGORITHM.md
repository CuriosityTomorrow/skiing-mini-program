# Ski Score 评分算法说明文档

## 概述

Ski Score 是一个多维度评分系统，灵感来自 Nomads.com 的 Nomad Score。通过客观数据计算6个维度的分数，帮助用户做出数据驱动的决策。

---

## 评分维度

### 1. Overall Score（综合评分）0-10 分

**定义**：滑雪场的综合质量评分

**权重分配**：
- 雪道质量：30%
- 设施完善度：25%
- 用户评分：20%
- 人气值：15%
- 性价比：10%

**计算逻辑**：
```javascript
综合评分 = 雪道质量 × 0.30
        + 设施完善度 × 0.25
        + 用户评分标准化 × 0.20
        + 人气值标准化 × 0.15
        + 性价比 × 0.10
```

**典型分数**：
- 9.0-10.0：世界级度假区（如万龙、云顶）
- 8.0-8.9：优质滑雪场（如太舞、富龙）
- 7.0-7.9：良好滑雪场（如南山、军都山）
- 6.0-6.9：一般滑雪场
- <6.0：基础滑雪场

---

### 2. Beginner Score（新手友好度）0-10 分

**定义**：滑雪场对初学者的友好程度

**考虑因素**：
1. **初级雪道比例**（40%）
   - ≥40%：4.0 分
   - 25-40%：3.0 分
   - 15-25%：2.0 分
   - <15%：1.0 分

2. **关键设施**（30%）
   - 魔毯：1.5 分
   - 教练服务：1.0 分
   - 租赁服务：0.5 分

3. **雪道总数适中性**（15%）
   - 8-20 条：1.5 分（最适合）
   - 20-30 条：1.0 分
   - <8 条：0.5 分

4. **安全和便利设施**（15%）
   - 储物柜、餐厅、停车场各 0.5 分

**典型分数**：
- 8.0-10.0：极度新手友好（如南山、渔阳）
- 6.5-7.9：新手友好（如多乐美地）
- 5.0-6.4：一般（如万龙）
- <5.0：不建议新手

---

### 3. Intermediate Score（中级友好度）0-10 分

**定义**：滑雪场对中级滑雪者的吸引力

**考虑因素**：
1. **中级雪道数量**（40%）
   - ≥10 条：4.0 分
   - 6-9 条：3.0 分
   - 3-5 条：2.0 分
   - <3 条：1.0 分

2. **雪道总数**（20%）
   - ≥20 条：2.0 分
   - 12-19 条：1.5 分
   - 8-11 条：1.0 分

3. **设施**（20%）
   - 缆车/索道：1.5 分
   - 租赁服务：0.5 分

4. **垂直落差**（20%）
   - ≥500 米：2.0 分
   - 300-499 米：1.5 分
   - 150-299 米：1.0 分
   - <150 米：0.5 分

**典型分数**：
- 8.5-10.0：中级天堂（如太舞、万龙）
- 7.0-8.4：适合中级（如云顶）
- 5.5-6.9：一般
- <5.5：中级雪道少

---

### 4. Expert Score（高手推荐度）0-10 分

**定义**：滑雪场对高级/专家级滑雪者的吸引力

**考虑因素**：
1. **高难度雪道数量**（40%）
   - 计算方式：(高级道数 + 专家道数 × 1.5)
   - ≥12：4.0 分
   - 8-11：3.0 分
   - 5-7：2.0 分
   - <5：1.0 分

2. **垂直落差**（30%）
   - ≥600 米：3.0 分
   - 400-599 米：2.0 分
   - 250-399 米：1.0 分

3. **最长雪道**（15%）
   - ≥3000 米：1.5 分
   - 2000-2999 米：1.0 分
   - 1000-1999 米：0.5 分

4. **特色设施**（15%）
   - 单板公园：1.0 分
   - 缆车/索道：0.5 分

**典型分数**：
- 9.0-10.0：高手天堂（如万龙、云顶）
- 7.5-8.9：高手推荐（如太舞、北大湖）
- 6.0-7.4：有高级道（如多乐美地）
- <6.0：高级道少

---

### 5. Family Score（亲子友好度）0-10 分

**定义**：滑雪场对家庭带孩子的友好程度

**考虑因素**：
1. **儿童区域**（25%）
   - 有：2.5 分
   - 无：0 分

2. **初级雪道比例**（25%）
   - ≥30%：2.5 分
   - 20-29%：2.0 分
   - 10-19%：1.5 分

3. **便利设施**（30%）
   - 餐厅：1.0 分
   - 储物柜：0.5 分
   - 停车场：0.5 分
   - 租赁服务：0.5 分
   - 住宿：0.5 分

4. **安全和服务**（20%）
   - 教练服务：1.0 分
   - 魔毯：1.0 分

**典型分数**：
- 8.5-10.0：家庭首选（有儿童区、设施完善）
- 7.0-8.4：适合家庭（设施较好）
- 5.5-6.9：一般
- <5.5：不太适合带孩子

---

### 6. Value Score（性价比）0-10 分

**定义**：花费与获得的价值比

**考虑因素**：
1. **价格评估**（30%）
   - <250 元：3.0 分（超值）
   - 250-399 元：2.5 分（实惠）
   - 400-549 元：2.0 分（适中）
   - 550-699 元：1.5 分（偏贵）
   - ≥700 元：1.0 分（昂贵）

2. **雪道数量**（25%）
   - ≥30 条：2.5 分
   - 20-29 条：2.0 分
   - 12-19 条：1.5 分
   - 6-11 条：1.0 分
   - <6 条：0.5 分

3. **设施完善度**（25%）
   - 基于11种设施的可用性
   - 11 个全有：2.5 分
   - 按比例递减

4. **用户评分**（20%）
   - 用户评分高说明物有所值
   - 5 星：2.0 分
   - 4 星：1.6 分
   - 3 星：1.2 分

**典型分数**：
- 9.0-10.0：超高性价比（便宜且质量好）
- 8.0-8.9：性价比高
- 7.0-7.9：性价比不错
- 6.0-6.9：一般
- <6.0：性价比低

---

## 辅助算法

### 雪道质量评估

**权重分配**：
- 雪道总数：40%
- 雪道分布多样性：30%
- 垂直落差：20%
- 最长雪道：10%

**多样性计算**：
- 4 种难度都有：1.0（最佳）
- 3 种难度：0.8
- 2 种难度：0.6
- 1 种难度：0.3

### 设施完善度评估

统计11种设施的可用性：
- rental（租赁）
- parking（停车）
- restaurant（餐厅）
- hotel（住宿）
- locker（储物柜）
- nightSkiing（夜场）
- coach（教练）
- magicCarpet（魔毯）
- cableCar（缆车）
- snowPark（单板公园）
- kidsArea（儿童区）

**计算公式**：
```
设施分数 = (可用设施数 / 11) × 10
```

## 使用场景

### 1. 新手选择滑雪场
```javascript
// 按新手友好度排序，找初级道多、有教练的滑雪场
sortBy: 'beginner_score'
filters: {
  requiredFacilities: ['coach', 'rental', 'magicCarpet']
}
```

### 2. 高手寻找挑战
```javascript
// 按高手推荐度排序，找高级道多、落差大的滑雪场
sortBy: 'expert_score'
filters: {
  difficulty: ['advanced', 'expert'],
  minTrails: 20
}
```

### 3. 家庭周末游
```javascript
// 按亲子友好度排序，找有儿童区、设施完善的滑雪场
sortBy: 'family_score'
filters: {
  requiredFacilities: ['kidsArea', 'restaurant', 'parking'],
  suitableFor: ['family', 'weekend']
}
```

### 4. 预算有限
```javascript
// 按性价比排序，找便宜但质量不错的滑雪场
sortBy: 'value_score'
filters: {
  priceLevel: 'budget',
  minRating: 4.0
}
```

## 算法优化方向

### 短期优化
1. 增加季节因素（雪质、开放时间）
2. 考虑地理位置（距离用户距离）
3. 动态权重（根据用户画像调整）

### 长期优化
1. 机器学习优化权重
2. 用户反馈调整算法
3. 实时数据更新（当前人流、雪质）
4. 个性化评分（根据用户历史偏好）

---

## 数据要求

### 最小数据集
- name（名称）
- type（类型）
- trails.total（雪道总数）
- pricing.avgCost（平均价格）

### 推荐数据集
加上：
- trails 分布（beginner/intermediate/advanced/expert）
- facilities（设施信息）
- community.rating（用户评分）
- popularity（人气值）

### 完整数据集
包含所有 SkiResort schema 字段

## API 使用

```javascript
import { ResortScoringService } from '@/domain/resort/services/ResortScoringService.domain.js'

const scoringService = new ResortScoringService()

// 单个评分
const scores = scoringService.calculateAllScores(resort)

// 批量评分
const resortsWithScores = scoringService.calculateScoresForResorts(resorts)

// 访问特定分数
console.log(resort.scores.overall)      // 综合评分
console.log(resort.scores.beginner)     // 新手友好度
console.log(resort.scores.expert)       // 高手推荐度
console.log(resort.scores.family)       // 亲子友好度
console.log(resort.scores.value)        // 性价比
```
