## 数据流图

### 1. 搜索滑雪场数据流

```
┌──────────┐
│   用户    │
└─────┬────┘
      │ 输入搜索关键词
      ▼
┌─────────────────────────────────────────┐
│  搜索页面 (Vue Component)               │
│  - 用户输入"北京"                       │
│  - 调用 useResortList().handleSearch()  │
└──────────────┬──────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────┐
│  ResortSearchAppService (应用层)        │
│  - 构建搜索条件 ResortSearchCriteria    │
│  - 调用领域服务                         │
└──────────────┬──────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────┐
│  ResortSearchService (领域层)           │
│  - 判断是否有搜索关键词                 │
│  - 决定查询策略                         │
└──────────────┬──────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────┐
│  ResortRepositoryImpl (基础设施层)      │
│  - 查询云数据库缓存                     │
│  - 缓存未命中则调用高德API              │
│  - 保存结果到缓存                       │
└──────────────┬──────────────────────────┘
               │
        ┌──────┴──────┐
        │             │
        ▼             ▼
┌──────────────┐ ┌──────────────┐
│ 云数据库缓存  │ │  高德地图API  │
│ resorts集合   │ │  POI搜索     │
└──────────────┘ └──────────────┘
        │             │
        └──────┬──────┘
               │ 返回滑雪场列表
               ▼
┌─────────────────────────────────────────┐
│  ResortSearchService (领域层)           │
│  - 计算 match score（相关度）           │
│  - 排序                                 │
│  - 应用筛选条件                         │
└──────────────┬──────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────┐
│  ResortMapper (应用层)                  │
│  - Resort实体 → ResortDTO               │
└──────────────┬──────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────┐
│  搜索页面 (Vue Component)               │
│  - 更新 resorts ref                     │
│  - 渲染列表                             │
└──────────────┬──────────────────────────┘
               │
               ▼
┌──────────┐
│   用户    │
│ (看到列表) │
└──────────┘
```

### 2. 收藏滑雪场数据流

```
┌──────────┐
│   用户    │

      ▼
┌─────────────────────────────────────────┐

│  - 验证用户登录                         │
│  - 检查是否已收藏                       │

               │
               ▼
┌─────────────────────────────────────────┐
│  FavoriteDomainService (领域层)         │
│  - 验证业务规则                         │

               ▼

               ▼

│  详情页面 (Vue Component)               │

│  - 显示成功提示                         │

               │
               ▼
┌──────────┐
│   用户    │
│(收藏成功) │
└──────────┘
```

## 依赖关系图

```
表现层
    │
    │ 依赖 (调用)
    ▼
应用层
    │
    │ 依赖 (调用)
    ▼
领域层
    ▲
    │ 实现 (接口)
    │
基础设施层
```

**关键原则**：
