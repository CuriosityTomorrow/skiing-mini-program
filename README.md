# 滑雪场助手 - 微信小程序

一个帮助滑雪爱好者搜索和选择滑雪场的微信小程序。

## 项目功能

### 1. 搜索页面 (pages/index)
- 搜索栏：输入城市搜索最近的室内/室外滑雪场
- 结果按距离远近排序
- 显示滑雪场详细信息：
  - 城市、价格
  - 交通方式（高铁/飞机）和时间
  - 海拔、雪道数、雪季
  - 用户评分和评价数
- 可选中多个滑雪场进行对比
- 对比结果可分享给微信好友

### 2. 探索页面 (pages/explore)
包含三个子标签：

**按地区浏览**
- 按国家/城市分类浏览全球滑雪场
- 搜索国家和城市
- 展开查看该地区的所有滑雪场

**滑雪社区**
- 用户点评功能
- 查看其他雪友的体验分享
- 评价中显示用户信息作为参考：
  - 单板/双板
  - 滑雪时长
  - 滑雪水平
  - 性别、所在地

**找搭子**
- 发布和查看滑雪搭子信息
- 显示目标滑雪场、计划日期
- 显示发起人滑雪信息
- 申请加入功能

### 3. 个人资料页面 (pages/profile)
- 用户登录/授权
- 个人信息编辑：
  - 昵称、性别、年龄
  - 所在地
  - 滑雪类型（单板/双板/都玩）
  - 滑雪时长（雪季/雪时）
  - 滑雪水平标签：
    - 小白
    - 刚入门
    - 有点水平但不多
    - 艺高人胆大
    - 顶尖
    - 职业选手
    - 小趴菜
  - 微信号
- 查看我的评价、我的搭子、收藏

### 4. 滑雪场详情页面 (pages/resort)
- 滑雪场轮播图
- 详细信息展示
- 雪道分布可视化
- 交通方式详情
- 设施服务
- 用户评价预览
- 收藏、加入对比、分享功能

### 5. 对比页面 (pages/compare)
- 多个滑雪场并排对比
- 横向滑动查看
- 一键分享给好友
- 移除不需要的项目

## 使用说明

### 1. 准备开发环境
- 安装微信开发者工具
- 注册微信小程序账号
- 获取 AppID

### 2. 配置项目
1. 打开 `project.config.json`
2. 将 `appid` 字段修改为你的小程序 AppID

1. 点击"预览"按钮
2. 用微信扫描二维码
3. 在手机上查看效果

## 数据说明

项目使用模拟数据，包含：
- **15+个滑雪场**：涵盖中国、日本、瑞士、法国、美国、加拿大等
- **用户评价**：包含用户滑雪信息作为参考
- **滑雪搭子**：寻找同行的雪友

实际使用时需要：
1. 接入后端API
2. 替换 `data/resorts.js` 中的数据获取逻辑
3. 实现用户登录、发布、评论等功能

## 后续开发建议

### 必须实现
1. **后端API对接**：替换模拟数据
2. **用户系统**：完整的登录注册流程
3. **发布功能**：
   - 发布评价
   - 发布找搭子信息
4. **位置服务**：实时计算距离

### 可选功能
1. **地图展示**：滑雪场位置分布
2. **天气查询**：滑雪场天气状况
3. **雪道实时状态**：开放情况
4. **优惠券/活动**：促销信息
5. **社交功能**：关注、私信
6. **滑雪记录**：打卡、成就系统

## 技术栈
